# （2056 / 2160 / 2260 / 2361，四处形如

# 而分派器的结构看上去像是支持它；读代码的人会以为 x86 也能跑这一档。
# 记在附录 CU.5，不动代码。

# 「新增」之外的东西，需要人工确认后再处理。
